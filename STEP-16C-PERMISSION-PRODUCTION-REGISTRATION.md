# Step 16C — permission production registration checkpoint

**Decision: blocked; Permission=false.** `ToolPermissionPersistenceSource` is a concrete read-only exact-grant implementation. It checks UserId, ConversationId, ProjectId, canonical ToolId and required-permission metadata in one bounded query, requires an active user and owned Project conversation/project, and permits only `Status=Active` with `RevokedAt=null`. The EF configuration requires the opposite revoked shape (`Status=Revoked`, `RevokedAt` non-null). Duplicate grant results and malformed metadata fail closed. Generic `Permissions`, approval or tool metadata cannot substitute for this grant.

Step 15C states that the final reviewed permission evidence lacked a real revoked-grant fixture and would return `REVOKED GRANT CHECK: NOT PROVEN` / `RESULT: INCOMPLETE`. A reported partial live result is insufficient for production catalog approval. Therefore no `IToolPermissionSource` registration or `ReviewedPermission` entry is added. The future requirement is exactly one scoped `ToolPermissionPersistenceSource` registration, with its scoped `IAuraDbContext` dependency, no alternate/factory/instance fallback, reviewed physical grant constraint/index and grant issuance/revocation timing policy. The validator and exact source must be reviewed together.

To unblock, an operator must verify a disposable PostgreSQL target and real active and revoked fixtures, then run the gated read-only `--live-production-permission-evidence` command using Step 15C's secure PowerShell example. Capture the exact active grant PASS; wrong user, conversation, project, tool and requirement denials; real revoked-grant denial; inactive-user behavior; sanitized output and target identity. The command's `AURA_VERIFY_REVOKED_PERMISSION_GRANT_ID` must name a genuine revoked row. No live command was run here.

All composition fields and runtime flags remain false. The existing suite checks exact scope/metadata, revoked state, duplicate behavior and absence of fallback; the new checkpoint guard pins the unresolved evidence and registration state.
